*&---------------------------------------------------------------------*
*& ALV event handler
*&---------------------------------------------------------------------*
*       Only here because CL_GUI_ALV_GRID's per-cell F4 (ONF4) needs an
*       OO event handler - no FORM-based callback exists for it. Kept
*       everything else in FORMs as usual.
*&---------------------------------------------------------------------*
CLASS lcl_alv_event_handler DEFINITION FINAL.
  PUBLIC SECTION.
    METHODS on_f4 FOR EVENT onf4 OF cl_gui_alv_grid
      IMPORTING e_fieldname es_row_no er_event_data.
    METHODS on_data_changed FOR EVENT data_changed OF cl_gui_alv_grid
      IMPORTING er_data_changed.
    METHODS on_toolbar FOR EVENT toolbar OF cl_gui_alv_grid
      IMPORTING e_object.
ENDCLASS.

" Has to come after the class it's typed as, can't sit up in Global Data.
DATA go_alv_events TYPE REF TO lcl_alv_event_handler.
